# Pop la Mémoire 🎈

Jeu de mémoire inspiré du filtre TikTok des ballons, jouable sur téléphone dans le navigateur.

## Comment on joue

1. Des ballons apparaissent quelques secondes. Retiens où ils sont.
2. L'écran devient noir, « TIRE ! » s'affiche.
3. Tape à l'endroit de chaque ballon pour le faire éclater. Une balle par ballon, pas une de plus.

Tous les ballons éclatés : niveau suivant. Un seul raté : tu recommences le niveau, et les ballons manqués apparaissent en pointillé.

## Progression

- 30 niveaux répartis en 6 mondes : Fête foraine, Coucher de soleil, Océan, Forêt, Aurore boréale, Espace.
- Un ballon de plus à chaque niveau : 3 au niveau 1, 32 au niveau 30.
- La zone de tir se resserre à chaque monde.
- À partir du niveau 21, les ballons bougent pendant qu'il faut les mémoriser.
- La progression est gardée sur le téléphone et tous les niveaux débloqués se rejouent depuis « Choisir un niveau ».

## Mettre le jeu en ligne

Tout le jeu tient dans `index.html`. Pour y jouer depuis un téléphone :
Settings → Pages → Branch `main` → `/ (root)` → Save. Le lien apparaît après une minute environ.
